# 2026.01.05 - Journal - integration programs

## JSON parser smoke program
Added a small “real program” golden test to exercise core language features that don’t show up as
directly in the micro/golden unit-style programs: recursion, string scanning, list/dict mutation,
and error throwing.

New golden:
- `tests/golden/integration/json_parser_smoke.braw`
  - Subset JSON parser: strings (no escapes), integers (optional `-`), arrays, objects, and the
    `true`/`false`/`null` keywords.
  - Parses a small document and prints:
    - numeric sum of nested fields
    - parsed booleans + null (mapped to `aye`/`nae`/`naething`)

Expected output:
- `tests/golden/integration/json_parser_smoke.expected`

Validation:
- `timeout 600 cargo test --test golden_tests golden_tests_interpreter` ✅
- `timeout 900 cargo test --test golden_tests golden_tests_native --features llvm` ✅
