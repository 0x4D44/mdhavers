# Bogle Castle stage 5c: Arthur’s second playtest

Arthur requested a fuller HUD, relief from the background alarm, a clear level
objective/exit, wall-flat pictures, and playback for the concurrent music lane.
All shipped changes are mdhavers and baked BOG data. No Rust/C/runtime source,
dependencies, image generation, cargo, git writes, commits or external posts.
The lead owns git. Music composition, its sources, bake_music and music BMU data
were not edited by this code lane.

## Changes and cause

- `engine/render.braw:bogle_hud`: the 320x200 bar remains 44 rows but uses all
  its width: health/shortbread icons and large health/spirit numbers left of the
  face, large current ammo and Mars/shot/puff counts right, held airn/siller key
  icons, and a four-slot weapon strip. Owned weapons light, unowned dim, and the
  selected slot is underlined. Objective text derives from key bits: FIND AIRN
  KEY -> FIND SILLER KEY -> REACH THE GATE. At 80x50, native 3x5 glyphs occupy a
  19-row compact layout. A minimum 44-row full HUD also prevents out-of-bounds
  underline writes in a 320x150 framebuffer, found by cross-review.
- `shell/frontend.braw`, `shell/onboarding.braw`, `engine/map.braw`,
  `tools/mapbuild.braw`, `maps/e1m1.braw`: New Game and Restart enter a frozen
  briefing, from optional map `name` and repeated `briefing` records (six lines
  maximum, 68 characters each). Fresh any-key input dismisses it; mouse deltas,
  elapsed menu time and held fire cannot carry into play. Cross-review caught
  the host introducing Any Key only after entering the card, making held Enter
  look fresh. `bogle_front_menu` now tags held keys on every screen; the host
  preserves their edge identity across title -> briefing. Tests model this
  physical-host mapping. The compact briefing wraps native-size text. The exit
  has a painted WIN OOT / E: EXIT sign and a read-only E: win oot prompt using
  the same reach, facing and sight checks as the existing use trigger. The
  escaped message remains.
- `tools/decals.braw`, `tools/bake_decals.braw`, `engine/assets.braw`,
  `engine/things.braw`, `maps/e1m1.braw`, `data/e1m1.map`: cow, stag and banner
  are palette-indexed composites onto existing granite. Their E1M1 billboard
  things (34/30/35) are removed. Four solid edges are split into 64-unit panels;
  sector count, floors, ceilings and every portal stay unchanged. Explicit
  directed wall overrides select ids15 cow,16 stag,17 banner,18 exit. Texture
  perspective, near clipping and lighting now do all picture projection. The
  invisible exit actor retains its original coordinates/use behavior (flag2
  hides its former banner sprite). Armour, brazier, thistle and curling stone
  remain blocking sprites. No new image sources were generated.
- `audio/mixer.braw`, `shell/frame.braw`: the alarm evidence points to midges.
  The original cue swept a high square/reed tone 1200..1700 Hz at amplitude4000
  for6000 samples, but the engine repeats it every7 tics =4410 samples. The
  actual671-tic E1M1 replay emitted31 midge cues;29 arrived while an earlier
  buzz was active. Longest continuous activity was129 tics (3.69 seconds),
  with223 active tics overall. The new profile is a noise-heavy flutter at
  amplitude900 for1800 samples: zero overlaps,93 active tics, longest run3
  tics (86ms at the probe’s tic resolution). This is listen-free evidence for
  the likely sound Arthur described, not proof of his exact listening session.
  Before/after PCM WAVs are `.scratch/audio5c/alarm-before.wav` and
  `alarm-after.wav` (845504 bytes each, complete19.17-second replay). Slot-zero
  pipes now reconcile against active play, selected pipes, live player, charge,
  held fire and menu-blocked fire every frame. Drone amplitude3600 ->1200;
  release of its cause fades over256 samples. One-shot profiles otherwise stay
  unchanged except the deliberately shortened midge effect.
- `audio/mixer.braw:bogle_music_load/bogle_music_sample`, `shell/frame.braw`:
  optional title/gatehouse BMU files validate BMU1,22050 Hz,N,L and exact size.
  Missing/invalid files produce silence. Standard G.711 mu-law expands through
  an integer table; intro0..N plays once, then L..N repeats without a gap.
  Play selects gatehouse, every other screen title. Music gain48/256 sits below
  the effects, with512-sample (23ms) track crossfades and mute fades. Pause adds
  Music ON/OFF; M works on every screen. Mute preserves the moving track cursor,
  restart preserves the setting and music state while resetting effects. A
  final regression caught stale gain when muting during a missing-track gap;
  an empty source/tail now clears gain so a later muted track cannot chirp.
  The concurrent lane owns track composition and the two actual BMU assets.
