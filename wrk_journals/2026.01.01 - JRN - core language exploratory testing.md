  - `tests/golden/data_structures/set_membership_mismatch_int_vs_string.*`
- Hardened LLVM native builtins that treat `Value.data` as a `char*`:
  - Added explicit string type checks for `starts_wi` / `ends_wi` and route mismatches through `__mdh_type_error` (catchable; prevents segfaults).
  - Added golden regression test: `tests/golden/edge_cases/starts_ends_wi_type_error_caught.*`.
- Re-verified `timeout 2100 bash scripts/coverage_guardrails.sh` stays green after the changes.
- Extended + hardened string/list builtins across backends:
  - Interpreter: `wheesht` now supports filtering falsy values from a list (in addition to trimming strings).
  - LLVM native: `wheesht` now dispatches by runtime tag (list vs string) rather than compile-time inference (prevents miscompile/segfault on unknown types).
  - LLVM native: `upper` / `lower` now type-check string inputs and throw via `__mdh_type_error` on mismatch (catchable; prevents segfaults).
  - New goldens:
    - `tests/golden/data_structures/wheesht_filters_falsy_list.*`
    - `tests/golden/edge_cases/upper_lower_wheesht_type_error_caught.*`
- Fixed a coverage guardrail regression caused by the new `wheesht` list filter closure instantiation:
  - Added a direct unit test in `src/interpreter.rs` to exercise `wheesht([..])` under coverage.
  - Kept a coverage-only integration test `tests/interpreter_wheesht_list_coverage.rs` to ensure both crate instances execute the list branch.
- Hardened `coont` in the LLVM backend to match interpreter semantics and avoid pointer crashes:
  - String case now checks that the needle is also a string before calling the substring-count implementation.
  - Non-list/non-string containers now throw via `__mdh_type_error` instead of returning `0`.
  - Added golden regression test: `tests/golden/edge_cases/coont_type_errors_caught.*`.
- Hardened `index_of` in the LLVM backend to match interpreter semantics and avoid pointer crashes:
  - Runtime tag dispatch now requires container to be list or string; otherwise throws via `__mdh_type_error`.
  - String case now requires the needle to be a string; otherwise throws.
  - Added golden regression test: `tests/golden/edge_cases/index_of_type_errors_caught.*`.
- Hardened `repeat` in the LLVM backend to match interpreter semantics and avoid hangs:
  - Added runtime type checks (string, int) and explicit negative-count `hurl` guard (prevents the previous unsigned-loop runaway).
  - Uses runtime `__mdh_repeat_say` for the actual repeat implementation.
  - Added golden regression test: `tests/golden/edge_cases/repeat_type_errors_and_negative_caught.*`.
- Added a new “string builtins safety” golden program to prevent regressions and pointer-unsafe crashes:
  - `tests/golden/edge_cases/string_builtins_type_errors_caught.*` (covers `char_at`, `chars`, `ord`, `chr`, `substring`, `pad_left`, `pad_right`).
- Fixed an interpreter hang hazard for negative padding widths:
  - `pad_left("x", -1, "0")` / `pad_right("x", -1, "0")` now return the original string (matches stdlib-style “already wide” semantics, avoids huge allocations).
  - Added unit tests: `test_pad_left_negative_width_no_pad`, `test_pad_right_negative_width_no_pad`.
- Hardened additional LLVM native string builtins to avoid treating non-string `Value.data` as a `char*`:
  - `ord`: type-checks string input and throws on empty string (match interpreter).
  - `chr`: type-checks integer input and rejects invalid codepoint ranges (catchable).
  - `char_at`: type-checks string input, coerces index (int/float), and uses the existing bounds-checked `compile_string_index` helper.
  - `chars`: type-checks string input.
  - `substring`: type-checks string input and coerces indices (int/float) before slicing.
  - `pad_left` / `pad_right` / `pad`: type-check string/width/(pad_char) to prevent `strlen`/pointer misuse.
- Fixed a subtle but serious native-vs-interpreter divergence in `pad_*` fill handling:
  - Native `inline_pad` previously treated an empty `pad_char` string as `'\0'` (NUL), producing truncated strings.
  - Now empty fill defaults to space, matching interpreter behaviour and avoiding embedded NULs.
  - Added golden regression test: `tests/golden/edge_cases/pad_empty_fill_defaults_to_space.*`.
- Verified (with timeouts):
  - `timeout 600 cargo test --test golden_tests golden_tests_interpreter`
  - `timeout 900 cargo test --test golden_tests golden_tests_native --features llvm`
  - `timeout 2100 bash scripts/coverage_guardrails.sh` (still green; interpreter missed regions <= codegen missed regions).
