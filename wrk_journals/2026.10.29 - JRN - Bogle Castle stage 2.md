## Scope and implementation

`games/bogle/engine/` contains integer fixed-point maths, committed-table trig,
BOGMAP loading and validation, flat portal rendering, circular collision and
sector tracking, and deterministic game state. The renderer implements near,
horizontal portal-window, and vertical column clipping, per-column flats, sky,
drawsegs, and generated light maps.

`shell/` supplies replay hashing and the native frame host. `tools/` supplies the
map builder, test-map generator, replay generator, and timing program. Only the
one-time sine-table generator uses Python. The Rust unit gate owns the engine
purity assertion. The standalone Rust acceptance tool uses the supplied trunk
compiler without invoking cargo.

The fixture has eleven convex sectors, including a step and lintel, four stairs,
a sky room, and an L-shaped room split into four sectors. Its 350-tic replay
crosses all ten physical portals.

The builder uses `map_thing` for the design's `thing` operation because `thing`
is a reserved language keyword. No language/compiler/runtime files were changed.

## Review corrections

- Vertex indices are checked before the validator reads coordinates for
  convexity. Collinear boundary vertices are permitted; positive area is required.
- Movement tracks several thin sectors crossed within one substep. Mouse input
  is reduced modulo one turn before subtraction. Movement deltas are bounded
  before absolute-value and substep arithmetic.
- The renderer preserves near portal apertures and uses an overflow-safe exact
  near-intersection calculation at opposite map bounds.
- The frame host retains fractional tic time when limiting a frame to four tics.
  Repeated 110 ms frames must produce 38 tics over 1100 ms.
- Headless positional options are selected before environment dimensions are
  parsed, so malformed overridden environment values cannot reject valid args.
- One new slide-test expectation was corrected during review: two four-unit
  substeps from x108 reach exact radius16 clearance at x112, then slide to y72.
  No existing repository assertion was changed.
