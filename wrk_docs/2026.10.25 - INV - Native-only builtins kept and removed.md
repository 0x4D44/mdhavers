# Native-only builtins: kept and removed (MDH-BUG-FLU-00145)

Date: 2026-10-25. Decision (Round 3, row 145): remove native placeholders, keep names that really work and list them.

Method: the 415 names in the native `compile_call` dispatch (`src/llvm/codegen.rs`) that the interpreter reports as `hasnae been defined yet` (checked against a built interpreter, one `ken x = NAME` probe per name). The bug counted about 410. Six more names the probe flags are parser keywords in the interpreter (`haud_yer_wheesht`, `log_whisper`, `log_mutter`, `log_blether`, `log_holler`, `log_roar`) and are out of scope. Each body was read and classified.

Result: **185 removed, 230 kept** (of 415). Removing an arm turns a call into the normal native path for an unknown name (the undefined-name error). User code or fetched stdlib that defines the same name still works, because user functions are resolved before the builtin dispatch.

## Left alone: native placeholders under interpreter-defined names

Out of scope for 145 (the interpreter defines these names, so the two backends disagree on behaviour rather than on existence). Listed for a follow-up bug: dae_times (nil), screen_end (nil), key_down and key_pressed (always nae), assert_that (nil), group_by (nil), compose (nil), nae_that (second argument), swatch (nil), same (always nae), apply_n (third argument), constant (argument), efter (list unchanged), scots_miles_tae_km, scots_pints_tae_litres and stanes_tae_kg (input unchanged), screen_width and screen_height (800 and 600).

The prelude globals __current_suite, _tick_counter, _msg_counter, _verbose, __prop_passed, _global_bus and _global_logger (codegen.rs ~5048) are still predeclared; only their dead dispatch arms were removed.
