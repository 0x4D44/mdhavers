# Coverage Improvement Plan (Next Stage)

Date: 2025.12.30  
Scoreboard source of truth: `target/llvm-cov-summary.json` (canonical `cargo llvm-cov` command).

## Goals

1. Keep canonical floors:
   - `functions.percent == 100`
   - `instantiations.percent == 100`
2. Keep hotspot ordering:
   - `src/interpreter.rs` missed regions **<** `src/llvm/codegen.rs`
3. Avoid flaky tests:
   - Prefer thread-local overrides over process-global mutations (env/CWD).
   - Always run long commands with `timeout`.

## Stage 1 — Eliminate small per-file misses (low risk)

### 1A) `src/error.rs` (1 line / 1 region)

- Use instantiation-aware output to find the exact remaining `^0`/`| 0|` contributor:
  - `timeout 600 cargo llvm-cov --no-default-features --features cli,llvm,native --text --show-instantiations --output-path target/llvm-cov-text-inst-current.txt --no-run`
- Add one **coverage-only** integration test in `tests/` that executes the missing path in the dependency crate instance (similar to existing error-suggestion tests).
- Re-run canonical summary and confirm `src/error.rs` reaches 0 missed lines/regions (if feasible without adding new misses elsewhere).

### 1B) `src/compiler.rs` (2 lines / 2 regions)

- Identify which error branches are still uncovered in the dependency/binary instances (tri-alias is one common culprit).
- Add targeted coverage-only integration tests that call:
  - `mdhavers::compiler::compile(...)` directly (dependency instance), and/or
  - CLI subprocess coverage (`tests/cli_coverage.rs`) if the miss is in a CLI-only instantiation.
- Re-run canonical summary after each small change (avoid large batches).

### 1C) `src/main.rs` (2 lines / 8 regions)

- Generate instantiation-aware report and pinpoint which instance(s) still miss the branches.
- Prefer:
  - unit tests in `src/main.rs` for test-harness-only instantiations
  - CLI subprocess tests for binary-only instantiations
- Avoid adding assert branches that only execute on failure (e.g. `assert!(cond, "…{var}")`) inside `src/` files, as they can create uncovered regions.

## Stage 2 — Hotspot work (measurable, but higher effort)

### 2A) `src/llvm/codegen.rs`

- Use `target/llvm-cov-text-inst-current.txt` and/or HTML reports to find the largest `^0` clusters.
- Add a small number of deterministic LLVM compilation tests that:
  - cover missing construct/statement kinds
  - cover common error paths (invalid AST inputs, unsupported constructs)

### 2B) `src/interpreter.rs` (keep below codegen)

- Only take changes that either:
  - reduce interpreter missed regions, or
  - keep interpreter misses unchanged while reducing codegen misses more

## Stage 3 — Guardrails

- Add (or extend) a small script target to:
  - run canonical coverage with a timeout
  - parse `target/llvm-cov-summary.json`
  - fail CI/local runs if floors/hotspot ordering regress
