# DES - RC borrowing (native backend, round R5)

**Date:** 2026-10-26
**Parent:** `2026.10.25 - DES - R1 refcount insertion plan.md`; DEC "Round 4 decisions" (RC stays opt-in;
one more round: borrowing analysis plus a list-buffer cache, then decide again with numbers).
**Scope:** `src/llvm/codegen/rc.rs`, a few call sites in `src/llvm/codegen.rs`, `runtime/gc_stub.c`,
`runtime/mdh_runtime.c` (list buffers only), native RC tests. Everything stays behind `MDH_RC=1`:
with it unset the emitted IR is byte-identical to trunk.

## 1. Where the cost is (trunk, instruction counts)

R4 already borrows parameters and local reads inside a statement. What is left is the
**expression-result rule**: every value an expression reads out of a holder it does not own
(a global, a list element, a field, a captured cell, a parameter read outside a statement such
as a lambda's expression body) is retained into a temp and released when the statement ends.
For an integer that is two tag tests; for a heap value an inline count update each way. In the
hot loops of `list`, `particle_sim`, `closure` and `method` that pair is most of the RC cost.

## 2. Borrowing: drop the retain/release pair when nothing can free the value meanwhile

A value `v` read from a holder stays alive while the holder keeps its reference. Every way a
reference is dropped in generated code is a **call** at the point this pass runs (before the
inline fast paths are emitted): `__mdh_release`/`__mdh_rc_release_obj`, `__mdh_shared_store`,
a runtime function that overwrites, removes or frees, `__mdh_obj_realloc`, or user code
(a compiled function, lambda, method, dispatcher, an indirect call, or a runtime function that
calls back into user code). Plain stores never drop a count. So:

> If, on every path from the retain to the last use of `v` (or of anything that points into
> `v`'s object), there is no call that can drop a reference or run user code, the retain and
> the temp's release can both go.

Mechanism (module post-pass `rc_elide_borrows`, after the epilogues, before the fast paths):

1. **Markers.** Every retain the codegen emits for a value it borrows is a call to a marker,
   `__mdh_rc_borrow_retain(v)`, recorded as an `RcBorrow` with the temp's park store `P` (the
   only store of a non-nil value into that temp slot). Three sources:
   - `rc_own_temp` of a borrowed expression result. When the value is a phi whose incoming
     edges are partly fresh (+1 already, e.g. a call result) and partly borrowed (an element
     load), `rc_take_phi_by_edges` puts one marker on each borrowed edge and the record is
     `owned_edges`.
   - `rc_shared_load`'s single-thread branch (a global read). The record also holds the
     `__mdh_shared_load` call and the global (`holder_slot`).
   - `rc_note_write` (a local read in a statement that later writes the same local), with the
     local's slot as `holder_slot`.
   `rc_move_from_temp` (a `gie` or a store taking the temp's reference) marks the record
   `keep`: its retain is needed.
2. **Decision.** A record is elided when all of these hold; otherwise each marker becomes an
   ordinary `__mdh_retain` call (exactly the code R4 emitted):
   - the program can never start a thread (no use of `__mdh_thread_spawn`, R4's test);
   - not `keep`, and `P` exists;
   - **derived values** (`v` and, transitively, `extractvalue`/`insertvalue`, int/pointer casts,
     `getelementptr`, loads through derived pointers, `phi`/`select`/`freeze`, and the results
     of calls taking a derived argument unless the callee's ownership row says the result is
     fresh or not a heap value) do not **escape**. An escape is a store of a derived value into
     a scratch alloca (an alloca that is not a variable slot, not a temp slot and not `rc_ret`)
     whose address is used other than by plain loads and stores. A scratch alloca used only by
     loads and stores (a call's argument binding) just carries the value: its loads are more
     uses. A store into a variable slot, a temp slot, a list element or a field always comes
     with its own retain (`store_slot` / `rc_take`), and a return takes its own +1
     (`rc_return_value`), so neither is an escape. `invoke`/`callbr`/atomics bail out;
   - a phi use of a derived value inside `v`'s own defining block bails out (a loop back-edge
     would carry an old iteration's value past a new marker);
   - **region**: no unsafe instruction on a path from each marker to a derived use. The region
     is the marker's block after the marker, then the blocks forward-reachable from it that
     can also reach a use backwards (the backward walk does not pass through the marker's
     block or out of `v`'s defining block), scanned up to the last use.
3. **Unsafe instructions** (`rc_call_effect` gives each call `None`, `Drops` or `RunsCode`):
   - `RunsCode`: an indirect call, a call to a function defined in the module, `qsort`, a
     runtime function of a callback family (`log_`, `thread`, `timer`, `event`, `chan_`,
     `mutex`, `condvar`, `atomic`, `native`, `tri_`, audio, `call`), or a runtime function with
     no ownership row (the default for anything unknown).
   - `Drops`: `free`/`realloc`, a release/realloc/clear/remove family, or a runtime function
     whose ownership row has an `m` (mutated) or `s` (stored) argument.
   - `None`: retains, the marker, `__mdh_list_push`, allocation, libc readers, inline asm,
     intrinsics.
   - With no `holder_slot`, any `RunsCode`, or any `Drops` except the release of a temp's old
     value on re-park (a load named `rc_tmp_old*` from a holder slot: that temp is nil or holds
     another value), is unsafe.
   - With a local `holder_slot`, only a store to that slot or a `Drops` call passed its address
     is unsafe: no other code can reach an unboxed local.
   - With a global `holder_slot`, a store or `Drops` call on the global is unsafe, and so is a
     `RunsCode` call unless it calls a compiled function outside the **global writers** set:
     functions that store or `__mdh_shared_store` a user global, make a `RunsCode` call that
     is not a direct call of a compiled function, pass a global to a `Drops` call, or call
     (transitively) such a function.
   - Native method calls are `Drops`, not `RunsCode`, when the program cannot make a native
     object (no use of `__mdh_tri_module`, `__mdh_log_span_begin`, `__mdh_log_span_current`):
     then they only raise a type error.
4. **Rewrite.** Elided: delete the markers and `P` (the temp stays nil, so its releases at
   statement end, early exits and re-park release nil and fold away). For `owned_edges`, `P`
   is kept and its value becomes a new phi with nil on the marked edges, so the fresh edges'
   +1 is still released. For a global read, the `__mdh_shared_load` call becomes a plain load.
5. **Heap test.** The inline retain/release tag tests the codegen emits are now
   `tag > 3 && (MASK >> tag) & 1`. Jump threading cannot see through `lshr MASK, tag`; the
   extra compare lets it fold the test on paths where the tag is a known immediate (the nil a
   temp holds after elision). The out-of-line fast-path functions keep the old form.

Soundness argument: in generated code a reference count only falls through a call (plain
stores never decrement; the slot writes that release the old value do it with a release call
after the store). So on the paths in question no count falls, the holder keeps its reference,
and every object reachable from it keeps a count >= 1. Single-threaded only. A `hurl` out of
the region skips the uses (a handler can only reach `v` through memory: a holder, whose write
retains, or an escape). Misclassification can only keep a retain, never drop a needed one, as
long as every call that can decrement is `Drops` or `RunsCode`; the default for an unknown
callee is `RunsCode`. Each new rule was checked by injecting its opposite: with the
`RunsCode` rule off, `borrowed_values_keep_a_reference_while_their_holder_can_let_go` prints
freed-and-reused strings (`xy1`) instead of `ab1`.

## 3. Moves for element stores

`xs[i] = e` (the generic list path and the fast list path) and `obj.f = e` on a found field
use `store_slot_move`: when a temp of the statement holds `e`, the element takes the temp's
reference (as R4 did for local stores) instead of a retain plus the temp's release.

## 4. List-buffer cache (runtime)

List item buffers (`__mdh_buf_alloc` from `__mdh_make_list` and inline list literals) are
freed by `__mdh_rc_free_buffers` when a list dies. Keep freed item buffers whose capacity is a
small power of two on per-size free lists (as R4's object cache), handed out again by
`__mdh_buf_alloc` for the same byte size. A buffer is malloc'd memory of at least that size, so
`realloc`/`free` on a reused buffer stay valid. Single-threaded only (drained at the first
spawn with the object cache), off under ASan, and only while counting is on. Eight classes
(16 to 2048 bytes, capacity 1 to 128), 128 buffers each. The list case of
`__mdh_rc_free_buffers` calls `__mdh_list_items_free(items, capacity)` instead of `free`.

Also in the runtime: a string that reaches zero (from `__mdh_rc_release_obj` or as a child of
a dying container) is finished at once (marked dead, counted, its block freed or cached)
instead of being pushed through the kill work list: strings hold no children or buffers.

The ~15% bar is met on 6 of 10 (fib, intloop, alloc, strbuild, dict, expr_eval); missed on
list, closure, method and particle_sim. What is left, from IR and `sample` profiles:

- **Tag tests on values of unknown type.** Releasing a slot's old value and retaining a value
  stored into a slot (`ken pj = particles[j]`) still test the tag at run time. particle_sim
  is almost all of this: its reads are already borrowed, its stores are not removable.
  Next: a light type inference (int/float locals and fields) to drop tests statically.
- **Values kept across user calls.** A read whose last use is after a call to compiled code
  that may write the holder (closure, method) keeps its retain. Next: per-function summaries
  of which holders a callee can drop (today only "writes no global" is summarised).
- **Locals holding a borrowed value.** `ken x = xs[i]` retains into the slot because the slot
  outlives the statement. Next: a "borrowed slot" (no retain or epilogue release when every
  use of the slot is in a region where the source holder cannot be dropped).
- **dict**: the rest is runtime (`__mdh_kv_find`, release of dead entries), not codegen.

## 7. Round R6 (2026-10-28)

Two rule changes and one post-optimiser pass, all behind `MDH_RC=1`:

- **(a) Rows borrow.** `rc_touches_slot` counts a value loaded from the holder slot only when
  the callee may release it: a release, free or realloc, or a function with no ownership
  row. Rows (`b`, `m`, `s`) never consume their argument object; `ownership.rs` states the
  invariant and `no_row_consumes_its_argument` guards it.
- **(b) A store that is the region's last use is safe.** A store drops nothing; the release
  of the old value after it is outside the region.
- **Tag split.** After `default<O2>`, `rc_split_tag_phis` gives each tag read of an
  `MdhValue` phi its own `i8` phi, then a short cleanup folds the heap tests. The module is
  verified after the split.

Defence in depth (no test can isolate them): (b)'s "is the last use" condition (every
release of a slot's old value follows its store, so the release rule already covers a
store with later uses), and (a)'s release/free/realloc name clause (every release of a
loaded slot value follows a store into that slot, which rule (b) checks).

Results: list +56.7% -> +0.8%, particle_sim +35.7% -> +15.1% (RC on vs off, instructions).
