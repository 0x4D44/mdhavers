## What changed since the last update

### 1) Coverage-run warnings eliminated

`cargo llvm-cov` no longer emits the noisy `unused_imports` warnings for the CLI and LSP binaries in test builds.

Changes:
- `src/main.rs`: gate imports that are only used in `#[cfg(not(test))]` code paths.
- `src/lsp/main.rs`: gate LSP capability types that are only used in `#[cfg(not(test))] main()`.

### 2) Error suggestion paths exercised more thoroughly (and a small bug fixed)

The `get_error_suggestion()` keyword/alias table in `src/error.rs` had many suggestion arms that were never matched by tests (hurting region coverage).

Changes:
- `src/error.rs`: added a unit test that enumerates additional “keyword alias” inputs to hit previously-unmatched suggestion arms.
- `src/error.rs`: made the `"String"` (type-ish) hint reachable by handling `"String"` before lowercasing, instead of having an unreachable match arm.

Result:
- `src/error.rs` regions improved to **1210 / 1212 = 99.8350%**.

### 3) Parser cleanup: remove unreachable span fallbacks

`src/parser.rs` had a few unreachable `previous() == None` fallbacks in `unary()` that were showing up as uncovered regions. These were simplified to `unwrap()` (safe given the parser’s token-advance invariants), improving region coverage.

### 4) LLVM compiler test coverage: exercise more optimization branches

`src/llvm/compiler.rs` gained a small coverage bump by:
- avoiding short-circuiting in one IR assertion (so both sides are evaluated under coverage),
- running the optimization pass selection for both **-O1** and **-O3** levels, and
- exercising the “null status pointer” safety branch in the internal `BuildStatusGuard` drop.

### 5) Parser + WASM import-scanner error/option branches exercised more thoroughly

Changes:
- `tests/parser_error_paths_coverage.rs`: expanded the table of parse-failure cases to hit additional
  error-propagation and precedence branches, plus added a small success parse for:
  - single-quote import paths (`fetch 'tri'`)
  - match string patterns (`whan "a"`, `whan 'b'`)
- `tests/wasm_import_scanner_coverage.rs`: added assert-without-message and additional slice forms to
  hit the `None` branches for optional slice parts.

Result:
- `src/parser.rs` missed regions dropped **80 → 23** (file regions now **99.28%**).
- `src/wasm_compiler.rs` missed regions dropped **68 → 30** (file regions now **98.79%**).

### 6) LLVM codegen hotspot cooled (big region win)

The remaining “region tail” was dominated by `src/llvm/codegen.rs`, largely due to unexercised `?`
error-propagation regions inside builtin dispatch arms.

Changes:
- `tests/llvm_codegen_builtin_sweep_coverage.rs`: add an “undefined identifier” probe (`cov_missing_arg`)
  in multiple argument positions to exercise `?` propagation branches inside builtin argument compilation.
- `src/llvm/codegen.rs`: remove unreachable error-propagation regions by making a few helpers infallible
  (no `Result`), specifically:
  - `coerce_i64`
  - `inline_ge_raw`
  - `inline_lt_raw`

Result:
- Overall **regions** improved from **98.7902% → 99.1223%**.
- `src/llvm/codegen.rs` missed regions dropped **697 → 335** (file regions now **99.39%**).

### 7) Instantiation coverage kept at 100%

During the codegen work, **instantiations** briefly dipped by 1 due to an uncovered instantiation
of `get_stack_trace()` under llvm-cov. This was fixed by ensuring the function isn't inlined in
coverage builds:
- `src/interpreter.rs`: `get_stack_trace()` now has `#[cfg_attr(coverage, inline(never))]`.

### 8) Interpreter region tail cooled further (panic + eval-propagation + DTLS deterministic failures)

Changes:
- `src/interpreter.rs`: refactor the large coverage-only native sweep to use `expect_string` / `expect_list`,
  and explicitly execute their panic branches via `catch_unwind` (removes several uncovered `let-else { panic! }` regions).
- `src/interpreter.rs`: expand `evaluate_propagates_operand_errors_for_coverage()` to exercise additional `?`
  propagation paths in `evaluate()` (unary, logical, method calls, list spread, dict initializer, range, slice,
  `speir` prompt eval, and f-string expression eval).
- `src/interpreter.rs`: extend `test_native_object_get_set_call` with a native-object method-call arg-eval error
  to cover the native method-call `evaluate_call_args(...)?` branch.
- `src/interpreter.rs`: add test-only DTLS failure-injection hooks and unit tests to deterministically cover
  early error-mapping branches in `dtls_handshake` (socket setup + connector/acceptor construction).
- `src/interpreter.rs`: add a deterministic DTLS keying-material failure injection test to cover the
  `Keying material failed: ...` error-mapping branch in `dtls_handshake`.
- `tests/interpreter_additional_paths_coverage_only.rs`: broaden integration coverage for interpreter
  error-propagation (missing identifiers, callback propagation, native log arg validation, JSON parse error cases,
  and thread/event error wiring).
- `tests/llvm_codegen_extra_constructs_coverage.rs`: call `is_nummer(...)` twice in one module to exercise
  both the `strtod` declare (`add_function`) and reuse (`get_function`) branches.

Result:
- `src/interpreter.rs` missed regions dropped **321 → 301** (file regions now **98.86%**).
- Overall missed regions dropped **903 → 879** (overall regions now **99.1891%**).
