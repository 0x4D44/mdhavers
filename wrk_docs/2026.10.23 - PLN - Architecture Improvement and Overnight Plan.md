# mdhavers: architecture improvement plan and overnight plan

**Date:** 2026-10-23
**Companion:** `2026.10.23 - HLD - mdhavers Architecture As-Built.md`
**Defect ledger:** `bugs/` (prefix `MDH`), started tonight.

## 1. Direction

mdhavers is a language whose main value is its personality and breadth. It is not a
production compiler. The target architecture should make the **interpreter boringly robust**,
make **every other backend measurably honest** against it, and **shrink** the code that
exists only for coverage or by copy-paste. A rewrite is not justified. The front end and
interpreter are sound in shape, and their failures are local.

### Target architecture (incremental, not a rewrite)

1. **One semantics, checked continuously.**
   - The golden corpus becomes a *differential* oracle. Every `tests/golden/**/*.braw` runs on
     the interpreter, JS (node), LLVM native and WAT (wasm_runner).
   - A checked-in per-backend allowlist records known gaps, so both a regression and a fix
     show up as a diff.
   - Every `SKIP_NATIVE` marker is re-justified or removed.
2. **Interpreter hardening.**
   - A call-depth limit raising the existing `HaversError::StackOverflow`, run on a
     large-stack thread.
   - Cycle-safe `Display`, equality and JSON.
   - Checked maths in every native.
   - No `RefCell` borrow held across user code.
   - Lazy trace formatting.

   Then a **builtin registry**: split `define_natives` by domain into modules, and give
   natives a context so the higher-order builtins stop being magic strings.
3. **A safe toolchain.**
   - `fmt` must refuse to write unless its output re-parses to the same AST. It should
     preserve comments, escape strings, and print floats and else-if chains faithfully.
   - Parser: ranges become a binary precedence level, plus a depth limit, linear-time
     dict/block disambiguation, and nesting-aware f-strings.
   - LSP: correct UTF-16 positions, and no unanswered requests.
4. **JS backend: a value shim, not raw JS operators.**
   - One literal escaper, identifier mangling, and runtime helpers reached through a
     namespace.
   - `__havers.display/eq/truthy/div` to match interpreter output.
   - *Open fork for Arthur:* int vs float in JS (BigInt, boxed float, or accept floats).
5. **LLVM backend: correctness before size.**
   - Invalidate or remove the shadow caches.
   - Structured try/catch (pop on `gie`/`brak`, entry-block `jmp_buf`, thread-local growable
     stack).
   - Overflow intrinsics.

   Then shrink:
   - Table-drive the 119 boilerplate builtin arms (reviving `builtins.rs`).
   - Collapse the comparison copies.
   - Move slow paths into the runtime, compiled to bitcode so they can still be inlined.

   Later, and each needing your go:
   - Upgrade to LLVM 18+ (inkwell bump, new pass manager).
   - Adopt a real GC or refcounting.
   - Port the C runtime incrementally to the Rust runtime.
6. **Repo hygiene (needs your go, because it deletes files).** Untrack the about 150 ELF
   binaries (about 41 MB), `tarpaulin-report.json`, the root `test_*` files,
   `editor/vscode/node_modules` and `docs/book/`. Consolidate the six duplicate stdlib pairs.
7. **Coverage regime (discussion).** Keep the 98% line gate. Drop the
   instantiation/hotspot-ordering guardrails and the in-production fault-injection seams.
   They cost more than they catch: none of tonight's crash bugs were caught by 99.8% coverage.

## 2. Design forks for Arthur and Edmund (not decided tonight)

| # | Question | Options |
|---|---|---|
| F1 | Equality of dicts and sets | structural, like lists (recommended); or identity, documented |
| F2 | Empty-dict truthiness | falsy, like the other empty containers (recommended) |
| F3 | Loop-variable binding | fresh per iteration, as JS `for…of` does (recommended); or shared |
| F4 | Top-level `gie` | error (`ReturnOutsideFunction`, recommended); or end the program |
| F5 | JS number model | BigInt ints; boxed floats; or accept float semantics in JS |
| F6 | LLVM upgrade target and GC strategy | LLVM 18 or 19 with Boehm, or with refcounting |
| F7 | Stdlib duplicates | which twin survives per pair |
| F8 | Repo hygiene deletions | approve the untrack list |

- Integrate each green unit as it lands, as you asked.
