# mdhavers: language and backend design decisions

**Date:** 2026-10-23
**Decided by:** Arthur
**Context:** the open forks in `2026.10.23 - PLN - Architecture Improvement and Overnight Plan.md` (section 2)
and the design questions raised by the overnight fix lanes. The interpreter is the reference semantics;
every decision below applies to all four backends (interpreter, JS, WASM, LLVM), the formatter and the docs.

## Decisions

| # | Question | Decision | Behaviour before |
|---|---|---|---|
| F1 | Dict and creel equality | **Structural**, like lists: equal keys and values / equal items | identity: `{"a": 1} == {"a": 1}` is nae |
| F2 | Empty-dict truthiness | **Falsy**, like the other empty containers | `{}` is truthy |
| F3 | Loop-variable binding | **Fresh per iteration**: closures capture that iteration's value | one shared binding: closures from `fer i in 0..3` all see 2 |
| F4 | Top-level `gie` | **Error** (`ReturnOutsideFunction`, Scots message), at check time where possible | interpreter ignores it; native emits an ill-typed return |
| F5 | JS number model | **BigInt for ints**: exact integer semantics incl. overflow errors; floats stay JS numbers | ints and floats are both JS numbers (rest of MDH-BUG-FLU-00043) |
| F6 | LLVM upgrade and memory | **LLVM 18/19 plus reference counting** in the C runtime and codegen | LLVM 15 pinned; native never frees (GC hooks point at a stub) |
| F7 | Stdlib duplicates | **`stdlib/` wins**: delete the `examples/lib/` twins, merge any functions only a twin has, point examples at `stdlib/` | six drifting pairs |
| F8 | Repo hygiene | **Untrack all four groups** (`git rm --cached` + `.gitignore`): ELF binaries + `tarpaulin-report.json`; root `test_*` files (check each first; move any a test reads into `tests/`); `editor/vscode/node_modules`; `docs/book/` | tracked |
| 64 | Block expression value | **Last expression**: a block's value is its final expression statement (`gie` still returns from the enclosing function) | `naething` unless `gie` |
| 72 | Forward global references | **Allow, like the interpreter**: native resolves any top-level global | native: "Undefined variable" |
| 83 | Six wrong LLVM tests | **Rewrite the tests** to exercise the builtins' real behaviour (`fankle` 2-arg interleave, `ceilidh` on lists, `lines` splits a string, `lst[100]` raises) | tests fail in both backends |
| - | Anonymous `dae(...) {...}` expressions | **No**: lambdas (`|x| ...`) are the only function expression | did not parse; one benchmark rewritten to lambdas |

## Notes for implementers

- F2 and 64 can change the meaning of existing programs. Run the golden corpus, the stdlib smoke test and the
  showcases on every backend, and grep `examples/`, `stdlib/` and `games/` for affected uses before landing.
- F1 equality must stay cycle-safe (reuse the iterative comparison in `src/value.rs`).
- F5 needs a mixed int/float arithmetic helper set in `runtime/js/core_runtime.js`; expect the JS parity
  allowlist to shrink.
- F6 is the largest item: bump inkwell, move to the new pass manager, then add refcounting. Plan it as its own
  design doc before building.
- F8 untracks files only; local copies stay. History is not rewritten.

## Round 2 decisions (Arthur, 2026-10-24 22:30 BST)

| # | Question | Decision |
|---|---|---|
| 96 | `dae` body implicit value | **Keep explicit `gie`**: a function body without `gie` returns `naething`. Only blocks and lambdas yield their last expression. By design; no code change. |
| 108 | `brak`/`haud` inside a block expression | **Parse error**, like top-level `gie` (F4): reject `brak`/`haud` whose nearest enclosing construct is a block expression rather than a loop, with a Scots message. A loop *inside* the block may still use them. |
| 115 | Prelude `pad_left`/`pad_right` signature | **Native wins**: 2 or 3 arguments, pad defaults to a space. The prelude must not shadow them with a stricter signature. |
| 114 | JS builtin categories | **Implement in JS**: bytes, date/time, regex (all hosts); file I/O and environment (Node only, clear error in a browser). **Not in JS**: sockets, TLS/DTLS/SRTP, threads/channels/mutexes, shell: each raises a clear "no available in JS" error and is documented as interpreter/native-only. |
| 90 | Native error line under threads | **Save/restore at fallible calls**: keep the cheap global line store on the hot path; make the line an error reports correct per thread without a thread-local write per statement. No measurable cost to single-threaded code (fib(32) stays within noise of 20.6 ms). |
| 91 | Native dict removal cost | **Tombstones**: removal marks the slot dead and compacts when more than half are dead; insertion order preserved. Inline reads use the hash index. |

| # | Question | Decision |
|---|---|---|
| 205 | After `fetch`, the interpreter gives the importer a copy of the module's globals; native shares one binding | **Share**: the importer and the module see one binding, so a write by either side is visible to the other. Make every backend match native. |
| 200 | Should the landing gate build `--all-targets` and the `cfg(coverage)` tests? | **Skip**: the gate stays as is. Bug closed wont-fix; lanes follow the `Makefile:coverage` lesson instead. |

| Showcase | A large app to show what mdhavers can build | **Yes, in principle**; design to be agreed before building. |

## Round 6 decisions (2026-10-28 17:43 GMT; Arthur delegated 206 and 207 to the lead)

| # | Question | Decision |
|---|---|---|
| 207 | After `fetch`, the importer declares `ken` with the name of a module global: native overwrites the shared binding, the interpreter makes a new binding that shadows it | **Shadow** (lead's ruling). A declaration always creates a new binding in its own scope; only assignment writes through a shared module binding (205). Native changes to match the interpreter. Reason: `ken` means "declare" everywhere else in the language, and a silent overwrite of another file's state is the more surprising outcome. |
| 206 | JS output for a program that `fetch`es `.braw` modules | **One bundled `.js` file** (lead's ruling): `mdhavers compile` compiles the entry file and every `.braw` module it reaches into one output, each module evaluated once, with globals shared per 205 and shadowing per 207. `fetch` of a non-`.braw` name keeps today's `require`. Reason: the playground and browsers take one file; one file per module would need a module loader. |
| RC default | RC still costs +15% on particle and about +69% on closure after R6; the rest is structural | **Redesign now, while the language is young** (Arthur). Design doc first (borrowing across index reads, kind-aware releases, callee summaries for closures), cross-family review, then build. RC becomes the default once every benchmark is under about 15% with no loss of safety; then ask Arthur to flip it. |
