## Changes in this iteration

### Guardrails automation (bounded + deterministic)

- Added `scripts/coverage_guardrails.sh` to:
  - run canonical coverage with `timeout`
  - assert floors:
    - `functions.percent == 100`
    - `instantiations.percent == 100`
  - assert hotspot ordering (current stage): `interpreter missed regions <= codegen missed regions`

- Fixed `Parser::return_statement` to treat end-of-file as a valid “no return value” terminator by using `is_at_end()` (previously `check(TokenKind::Eof)` could never be true).
- Added a unit test to lock the behavior.
