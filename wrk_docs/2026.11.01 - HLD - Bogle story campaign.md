# Bogle Castle: the story campaign (HLD)

Status: DRAFT (2L flow; reviews pending)

## 1. Goal

Turn Bogle Castle from two unconnected key-hunt levels into one comic story campaign:
rescue Princess Ailsa from Laird Angus McDreichBottom. The tone is Day of the Tentacle
x Doom x Portal: Doom-style fighting, adventure-game puzzles and inventory gags, and a
deadpan lab computer. Source: Arthur's story (2026-11-01 14:48) and decisions (14:54).

**In scope.** Five campaign levels, the engine features they need, new actors and art,
an ending chosen by campaign time, per-level replay oracles, the web build still working.

**Out of scope.** Save games, difficulty levels, voice acting, a new music score (each
level reuses the two existing tunes unless a new one is cheap), the Windows bridge,
publishing to 0x4d44.github.io (separate go), any language/compiler change.

- fast (under `BOGLE_END_FAST` seconds): "Ye mairry Ailsa. Ye hae seeven bairns. Yin o
  them is a clone."
- otherwise: "Ye mairry Ailsa. Ye hae nae bairns, but ye hae a verra guid personality
  core."

keeps the existing Restart / Back to Title screen, with a gravestone line: "HERE LIES
A SALESMAN" (decision D5).

## 3. Approach

The engine stays pure (no host calls, no floats, seeded randomness only) so every new
feature replays to identical hashes on the interpreter, native RC off/on and wasm.

### 3.1 Campaign (shell/frontend.braw)

- `bogle_levels()` becomes the five campaign maps. `e1m1.map` stays in `data/` with
  its tests as an engine regression map; it leaves the campaign (D1).
- `bogle_front_carry` adds `items` (a list of story item names, for example `"head"`)
  and `campaign_tics` (sum of finished levels' tics). Restart keeps what was carried in.
- The complete heading and the in-game won line use the map's `name`
  (`"THE KIRKYARD COMPLETE!"`), not the hardcoded Gatehouse strings.
- Winning level 5 goes to a new `ending` screen showing the tier text, the total time
  and Back to Title. The `dead` screen in level 5, and a countdown expiry, show the fail
  ending.

### 3.2 Story scripts (new engine/story.braw)

Per-level behaviour is code, not a map mini-language (D2). A map names its script with
a new record `story <id>`. `story.braw` dispatches on the id:

- `story_init(g)`: sets the objective line, the level's flags (`g["story"]`, a dict).
- `story_event(g, tag)`: called from `bogle_activate` for every link tag that fires
  (walk-over triggers and switches already produce tags), and from the new hooks below.
- `story_tick(g)`: once per tic after actors; level timers (the countdown, the clone).
- `story_use(g, actor)`: E on an NPC or story thing within 64 units with sight (the
  same test as the exit), for talking and the clone, the clock, the bell, the core.

A level script is a handful of small functions. Shared helpers: `story_say(g, lines)`,
`story_ask(g, lines, choices, then)`, `story_objective(g, text)`, `story_give(g, item)`,
`story_win(g)`.

`g["objective"]` replaces the hardcoded `bogle_hud_objective` when set; E1M1 and
E1M2-as-a-test-map keep their current HUD text (no `story` record, old function).

### 3.3 Dialogue and choices (engine)

`g["talk"]` = `{"lines": [...], "choices": [...], "sel": 0, "then": <event tag or "">}`.
While it is set, `tic` freezes the world (actors, projectiles, timers, `tics`, terrain)
and reads only: Use or Fire = advance or choose, forward/back = move the selection.
Keys must be released between presses (the menus' rule). It lives in the engine, not
the front end, so replays drive it with ordinary gameplay bits. Drawn as a box in the
lower third: up to 4 wrapped lines (a word-wrap helper over `bogle_text`, 3x5 font at
scale 1 at 320x200), choices with a `>` marker. Choosing sends `then` to
`story_event`. All choices in the gags lead to the same outcome; the text is the joke.

### 3.4 Locks and items

- Door lock values 3 (brass key, plant room) and 4 (retina: needs item `head`).
  `g["keys"]` stays a bitmask: brass = 4. The head is an item, not a key bit.
- Pickups: 22 brass key, 23 the clone's head (also spawned by the clone script).
- `BOGLE_REQUIRE_EXIT=1` asserts "won and alive" plus the map's own `require` record
  (for example `require keys 3 weapons 4` on E1M2, `require items head` on tower), so a
  map without two keys can still be checked (D7).

machine in the existing `state/timer` shape:

Night ghosts: ghosts can only be hurt in light above 96 (existing rule). The kirkyard
and forest keep lamp pools and moonlit clearings above 96 so ghosts stay beatable;
the map validator gets no new rule for this, the routes prove it.

### 3.6 The seen-o-meter (render.braw, tower only)

`story tower` sets `g["story"]["meter"] = aye`. The HUD draws a red gauge whose value is
a pure function of `tics` and the distance to the nearest lit doorway sector, so it
leaps about convincingly. It reads game state and writes nothing: a unit test plays the
same input with the meter on and off and asserts identical game state (D4).

### 3.7 Countdown and endings

`story lab` starts a 3-minute countdown on the computer's choice; the HUD shows it.
Freeing Ailsa (three levers, a link tag each, the script counts them) stops it. Expiry
sets `g["failed"]`; the front end shows the fail ending. Winning (core fitted) sets
`won`; the front end picks the tier from `campaign_tics + tics`.

### 3.8 Maps

`kirkyard`, `forest`, `tower`, `lab` are new builder scripts in `maps/`, in the e1m2
cell-collector style (rectangles plus inserted T-junction vertices), sky ceilings
outdoors. `distillery` is `maps/e1m2.braw` with the landing (shaft foot, fork, scanner
door) added west of the yard and the exit relabelled; it writes `data/distillery.map`
and E1M2 keeps its own map and oracle unchanged (D3). The landing room is a shared
helper (`maps/landing.braw`) used by `distillery` (open left, scanner locked) and `lab`
(rubble on the left, scanner opens with the head), so a "map changed by a story flag"
is two authored maps, not a runtime geometry change (D2).

### 3.9 Art

The existing Codex image pipeline (design 4.4: style preamble, magenta key, baker,
fixed palette). Batches by level so each level is reviewable on its own:

1. Kirkyard: Old Wullie (idle, walk 2, front plus `_a2.._a5`), grave, church stone wall,
   stained glass, pew panel, organ console, organ keys 1-4 (off/on switch faces),
   compressor (off/on), hymn board, crypt door, lamp post, brass key.
2. Forest: deer (idle, walk 2, charge, pain, death), thistle (hidden is no sprite, pop
   3 frames), tree (standing, falling 2, fallen), bark wall, hedge wall, earth tunnel
   wall, signposts, castle bell, footman, grandfather clock.
3. Cellars: rat (idle, walk 2, death), rubble, scanner door.
4. Tower: green cloak (2 poses), Ailsa clone (idle, sparks, boom), head pickup,
   panelled corridor, meter is drawn, not art.
5. Lab: Ailsa (strapped, free idle, throw), contraption (idle, walk 2, blast, vent,
   slumped), computer, levers (switch faces), cores, lab wall, pipes.

## 5. Acceptance criteria

1. New Game plays kirkyard -> forest -> distillery -> tower -> lab -> ending. A
   frontend replay crosses every level transition and the ending screen, three-way equal
   to its committed hashes.
2. Each campaign level has an autopilot route that completes it alive
   (`BOGLE_REQUIRE_EXIT=1`, with that map's `require`), replayed natively RC off/on
   equal to committed hashes, and the interpreter prefix agrees.
3. E1M1 and E1M2 keep their existing replays and hashes unchanged (they have no `story`
   record); every existing `games/bogle/tests` fixture still passes, or is re-blessed
   only where it pins something this design deliberately changes (listed in the
   journal with the reason).
4. Unit fixtures, each made to fail once:
   - talk freezes the world (actor positions and `tics` unchanged across talk tics)
     and choices move and choose with released keys;
   - "What do you think?" leads to "INTERPRETING VAGUE ANSWER AS NO." and starts the
     countdown;
   - Wullie: sees inside range and cone, not behind or beyond; drains health only
     while seeing; takes no damage;
   - organ: the right order opens the crypt; a wrong key resets; nothing before the
     compressor runs;
   - thistle pops and prods; tree falls on proximity and on standing still, hurts only
     on its line, falls once;
   - the meter changes nothing (game state equal with it on and off);
   - the clone drops the head; the scanner door opens only with it;
   - Ailsa follows and hurts only the Laird; the contraption vents and slumps; the core
     fits only with `good_core`;
   - ending tier from time; the countdown expiry and a level-5 death give the fail
     ending; earlier deaths give Restart.
5. `bogle_unit` engine purity scan stays green (no floats, bridge, clock or random names
   in `engine/`).
6. The web page builds from the branch (`games/bogle/web/build.sh`) and the kirkyard
   replay under node equals its native hashes.

## 6. Phasing (each phase is a committed green unit)

1. Engine: campaign carry, story hooks, talk box, locks 3/4, `require`, map-name
   headings, ending/fail screens; fixtures on a tiny test map.
2. Kirkyard (vertical slice): Wullie, graves, organ, art batch 1, route and hashes.
3. Forest: deer, thistle, tree, the wall gag and lobby, art batch 2, route.
4. Cellars: landing helper, distillery map, rats, art batch 3, route.
5. Tower: meter, cloaks, clone and head, art batch 4, route.
6. Lab: scanner, computer, countdown, Ailsa, contraption, core, endings, art batch 5,
   route; the campaign frontend replay.
7. Web build check, README, docs; code review and simplify passes.

## 7. Decision log

- **D1** E1M1 leaves the campaign but stays as a test map with its oracle. Arthur said
  replace the first level; keeping the file costs nothing and keeps its regression value.
- **D2** Story logic is braw code per level, not a map scripting language: smaller, typed
  by the language, easy to unit test. Story-changed geometry is two authored maps.
- **D3** E1M2 is reused as the cellars by building a separate `distillery.map` from the
  same script plus the landing; E1M2's own oracle stays unchanged.
- **D4** The meter is display only, and a test pins that.
- **D5** Dying in levels 1-4 keeps Restart (a story game that sends you back to the
  title for every death is tiresome); "buried alive" is the level-5 fail and a line on
  the death screen.
- **D6** Faster = mairry with bairns. Arthur said the marriage options depend on speed
  and did not say which is the reward; bairns read as the better ending. Easy to swap.
- **D7** `require` per map replaces the hardcoded two-key, four-weapon exit check.
- **D8** Thing types for new actors start at 40; kinds 6-8 are already used by assets.
- **D9** Arthur's "one way quickly finishes the level": read as the left way (the
  distillery) being the only way on the first visit; the right way is locked until you
  have the head. On the second visit rubble blocks the left.
