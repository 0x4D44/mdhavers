# High-Level Design: Windows Platform Support

**Date:** 2026-01-18
**Author:** Claude / Arthur
**Status:** Draft
**Version:** 1.0

## Executive Summary

This document describes two pieces of work required to achieve full Windows platform support for mdhavers:

1. **LLVM Runtime Windows Port** - Porting the C runtime library from POSIX to Windows APIs
2. **Unified Audio Abstraction** - Resolving symbol conflicts between raylib and miniaudio

Combined, these changes will enable the full feature set (`llvm`, `graphics`, `audio`) to work on Windows.

---

## Part 1: LLVM Runtime Windows Port

### 1.1 Problem Statement

The LLVM backend compiles mdhavers programs to native code, which links against a C runtime library (`runtime/mdh_runtime.c`). This runtime currently uses POSIX-only APIs that are unavailable on Windows:

```c
#include <dirent.h>      // Directory operations
#include <strings.h>     // strcasecmp, etc.
#include <sys/wait.h>    // Process waiting
#include <unistd.h>      // POSIX standard functions
#include <termios.h>     // Terminal I/O control
#include <sys/ioctl.h>   // Device I/O control
#include <sys/socket.h>  // BSD sockets
#include <netinet/in.h>  // Internet address family
#include <netinet/tcp.h> // TCP protocol
#include <arpa/inet.h>   // IP address conversion
#include <netdb.h>       // Network database operations
#include <fcntl.h>       // File control (partially available)
#include <poll.h>        // I/O multiplexing
#include <pthread.h>     // POSIX threads
```

### 1.2 Scope

**In Scope:**
- Platform abstraction for all POSIX APIs used in `mdh_runtime.c`
- Windows implementations using native Win32 APIs
- Maintaining feature parity with Unix implementation
- Build system updates for Windows compilation

**Out of Scope:**
- Performance optimization (parity first)
- Windows-specific features not present on Unix
- GUI/windowing (handled by raylib)

### 1.3 Technical Approach

#### 1.3.1 Architecture

Create a platform abstraction layer with compile-time selection:

```
runtime/
├── mdh_runtime.c          # Core runtime (platform-agnostic parts)
├── mdh_runtime.h          # Public API
├── platform/
│   ├── platform.h         # Platform abstraction interface
│   ├── platform_unix.c    # Unix/POSIX implementation
│   └── platform_win32.c   # Windows implementation
```

#### 1.3.2 API Mapping

| Category | POSIX API | Windows Equivalent | Notes |
|----------|-----------|-------------------|-------|
| **Directory Operations** |
| | `opendir()` | `FindFirstFileW()` | Use wide strings for Unicode |
| | `readdir()` | `FindNextFileW()` | |
| | `closedir()` | `FindClose()` | |
| | `struct dirent` | `WIN32_FIND_DATAW` | |
| **String Functions** |
| | `strcasecmp()` | `_stricmp()` | |
| | `strncasecmp()` | `_strnicmp()` | |
| **Process Control** |
| | `fork()` | `CreateProcess()` | No direct equivalent; redesign needed |
| | `exec*()` | `CreateProcess()` | Combined with fork |
| | `waitpid()` | `WaitForSingleObject()` | |
| | `kill()` | `TerminateProcess()` | |
| | `pipe()` | `CreatePipe()` | |
| **File Operations** |
| | `read()`/`write()` | `ReadFile()`/`WriteFile()` | Or use CRT `_read()`/`_write()` |
| | `close()` | `CloseHandle()` or `_close()` | |
| | `dup()`/`dup2()` | `DuplicateHandle()` | |
| | `fcntl()` | Various | Case-by-case |
| **Terminal I/O** |
| | `tcgetattr()` | `GetConsoleMode()` | |
| | `tcsetattr()` | `SetConsoleMode()` | |
| | `struct termios` | Console mode flags | |
| | `ioctl(TIOCGWINSZ)` | `GetConsoleScreenBufferInfo()` | |
| **Networking** |
| | `socket()` | `socket()` (Winsock) | Requires `WSAStartup()` |
| | `connect()` | `connect()` (Winsock) | |
| | `bind()`/`listen()` | Same (Winsock) | |
| | `accept()` | `accept()` (Winsock) | |
| | `send()`/`recv()` | `send()`/`recv()` (Winsock) | |
| | `close()` (socket) | `closesocket()` | Different function! |
| | `poll()` | `WSAPoll()` | Windows Vista+ |
| | `getaddrinfo()` | `getaddrinfo()` (Winsock) | Same API |
| | `inet_ntop()` | `InetNtopW()` | Wide string variant |
| **Threading** |
| | `pthread_create()` | `CreateThread()` or `_beginthreadex()` | |
| | `pthread_join()` | `WaitForSingleObject()` | |
| | `pthread_mutex_*` | `CRITICAL_SECTION` or `SRWLOCK` | |
| | `pthread_cond_*` | `CONDITION_VARIABLE` | |
| **Time** |
| | `gettimeofday()` | `GetSystemTimeAsFileTime()` | |
| | `nanosleep()` | `Sleep()` or `SleepEx()` | Millisecond precision |
| | `clock_gettime()` | `QueryPerformanceCounter()` | High-resolution |

#### 1.3.3 Platform Abstraction Interface

```c
// platform/platform.h

#ifndef MDH_PLATFORM_H
#define MDH_PLATFORM_H

#include <stdint.h>
#include <stddef.h>

#ifdef _WIN32
    #define MDH_PLATFORM_WINDOWS 1
#else
    #define MDH_PLATFORM_UNIX 1
#endif

// --- Directory Operations ---
typedef struct mdh_dir mdh_dir_t;
typedef struct mdh_dirent {
    char name[260];  // MAX_PATH on Windows
    int is_dir;
} mdh_dirent_t;

mdh_dir_t* mdh_opendir(const char* path);
mdh_dirent_t* mdh_readdir(mdh_dir_t* dir);
void mdh_closedir(mdh_dir_t* dir);

// --- Process Operations ---
typedef struct mdh_process mdh_process_t;

mdh_process_t* mdh_spawn(const char* program, char* const argv[],
                         int stdin_fd, int stdout_fd, int stderr_fd);
int mdh_process_wait(mdh_process_t* proc, int* exit_code);
int mdh_process_kill(mdh_process_t* proc);
void mdh_process_free(mdh_process_t* proc);

// --- Pipe Operations ---
int mdh_pipe(int fds[2]);
int mdh_pipe_read(int fd, void* buf, size_t count);
int mdh_pipe_write(int fd, const void* buf, size_t count);
int mdh_pipe_close(int fd);

// --- Terminal Operations ---
typedef struct mdh_terminal_state mdh_terminal_state_t;

int mdh_terminal_get_size(int* width, int* height);
int mdh_terminal_raw_mode(mdh_terminal_state_t* old_state);
int mdh_terminal_restore(const mdh_terminal_state_t* state);
int mdh_terminal_read_char(void);

// --- Networking ---
// (Most Winsock APIs are BSD-compatible, but need initialization)
int mdh_net_init(void);      // Call WSAStartup on Windows
void mdh_net_cleanup(void);  // Call WSACleanup on Windows
int mdh_socket_close(int sockfd);  // closesocket on Windows

// --- Threading ---
typedef struct mdh_thread mdh_thread_t;
typedef struct mdh_mutex mdh_mutex_t;
typedef struct mdh_cond mdh_cond_t;

mdh_thread_t* mdh_thread_create(void* (*func)(void*), void* arg);
int mdh_thread_join(mdh_thread_t* thread, void** retval);
void mdh_thread_free(mdh_thread_t* thread);

mdh_mutex_t* mdh_mutex_create(void);
void mdh_mutex_lock(mdh_mutex_t* mutex);
void mdh_mutex_unlock(mdh_mutex_t* mutex);
void mdh_mutex_free(mdh_mutex_t* mutex);

// --- Time ---
uint64_t mdh_time_monotonic_ns(void);  // Monotonic nanoseconds
void mdh_sleep_ms(uint32_t milliseconds);

// --- String Utilities ---
int mdh_strcasecmp(const char* s1, const char* s2);
int mdh_strncasecmp(const char* s1, const char* s2, size_t n);

#endif // MDH_PLATFORM_H
```

### 1.4 Build System Changes

Update `build.rs`:

```rust
fn main() {
    // ... existing code ...

    let target = env::var("TARGET").unwrap();

    let mut build = cc::Build::new();
    build
        .file("runtime/mdh_runtime.c")
        .include("runtime/platform")
        .opt_level(2);

    // Add platform-specific source
    if target.contains("windows") {
        build.file("runtime/platform/platform_win32.c");
        // Link Windows libraries
        println!("cargo:rustc-link-lib=ws2_32");  // Winsock
        println!("cargo:rustc-link-lib=userenv"); // Environment
    } else {
        build.file("runtime/platform/platform_unix.c");
        println!("cargo:rustc-link-lib=pthread");
    }

    build.compile("mdh_runtime");
}
```

### 1.5 Risks and Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| `fork()` has no Windows equivalent | High | Redesign process spawning to use spawn model |
| Unicode path handling | Medium | Use wide string APIs consistently |
| Socket API differences | Medium | Abstract close/error handling |
| Console vs TTY differences | Medium | Test thoroughly on Windows Terminal and cmd.exe |
| Thread local storage | Low | Use `__declspec(thread)` on Windows |

### 1.6 Testing Strategy

1. **Unit tests** for each platform API
2. **Golden tests** - ensure existing `.braw` tests pass
3. **Backend parity tests** - compare interpreter vs LLVM output
4. **Manual testing** of REPL and network features

## Part 2: Unified Audio Abstraction

### 2.1 Problem Statement

When both `graphics` and `audio` features are enabled, linker errors occur due to duplicate symbol definitions:

```
error LNK2005: ma_device_init already defined in libraylib_sys.rlib(raudio.obj)
error LNK2005: drwav_init already defined in libraylib_sys.rlib(raudio.obj)
error LNK2005: drmp3_init already defined in libraylib_sys.rlib(raudio.obj)
... (hundreds more)
```

**Root Cause:** Both libraries statically include:
- miniaudio (audio backend)
- dr_wav (WAV decoding)
- dr_mp3 (MP3 decoding)
- dr_flac (FLAC decoding)
- stb_vorbis (OGG decoding)

### 2.2 Scope

**In Scope:**
- Unified Rust audio API that abstracts backend choice
- Automatic backend selection based on enabled features
- Maintaining existing audio functionality
- MIDI synthesis support (via rustysynth, independent of conflict)

**Out of Scope:**
- Adding new audio formats
- Real-time audio processing
- Audio recording (if not currently supported)

### 2.3 Technical Approach

#### 2.3.1 Architecture

Create a unified audio module that selects the backend at compile time:

```
src/
├── audio.rs              # Current audio module → becomes unified API
├── audio/
│   ├── mod.rs            # Public API + backend selection
│   ├── backend_miniaudio.rs   # miniaudio implementation
│   ├── backend_raylib.rs      # raylib audio implementation
│   └── midi.rs           # MIDI synthesis (rustysynth, shared)
```

#### 2.3.2 Backend Selection Logic

```rust
// src/audio/mod.rs

// Backend selection at compile time
#[cfg(all(feature = "audio", not(feature = "graphics")))]
mod backend_miniaudio;
#[cfg(all(feature = "audio", not(feature = "graphics")))]
use backend_miniaudio as backend;

#[cfg(feature = "graphics")]
mod backend_raylib;
#[cfg(feature = "graphics")]
use backend_raylib as backend;

// MIDI is independent (rustysynth doesn't conflict)
#[cfg(feature = "audio")]
pub mod midi;

// Unified public API
pub use backend::{
    AudioEngine,
    Sound,
    Music,
    AudioStream,
};
```

#### 2.3.3 Unified Audio API

```rust
// src/audio/mod.rs

/// Audio engine handle - must be kept alive while using audio
pub struct AudioEngine {
    inner: backend::AudioEngineInner,
}

impl AudioEngine {
    /// Initialize the audio system
    pub fn new() -> Result<Self, AudioError>;

    /// Set master volume (0.0 - 1.0)
    pub fn set_master_volume(&mut self, volume: f32);

    /// Get master volume
    pub fn master_volume(&self) -> f32;
}

impl Drop for AudioEngine {
    fn drop(&mut self) {
        // Clean up audio system
    }
}

/// A loaded sound effect (short audio, fully loaded in memory)
pub struct Sound {
    inner: backend::SoundInner,
}

impl Sound {
    /// Load sound from file
    pub fn load(path: &str) -> Result<Self, AudioError>;

    /// Load sound from memory
    pub fn load_from_memory(data: &[u8], format: AudioFormat) -> Result<Self, AudioError>;

    /// Play the sound
    pub fn play(&self);

    /// Stop the sound
    pub fn stop(&self);

    /// Check if playing
    pub fn is_playing(&self) -> bool;

    /// Set volume (0.0 - 1.0)
    pub fn set_volume(&mut self, volume: f32);

    /// Set pitch (playback speed multiplier)
    pub fn set_pitch(&mut self, pitch: f32);

    /// Set stereo pan (-1.0 left, 0.0 center, 1.0 right)
    pub fn set_pan(&mut self, pan: f32);
}

/// Streamed music (large files, loaded progressively)
pub struct Music {
    inner: backend::MusicInner,
}

impl Music {
    /// Load music from file
    pub fn load(path: &str) -> Result<Self, AudioError>;

    /// Start/resume playback
    pub fn play(&mut self);

    /// Pause playback
    pub fn pause(&mut self);

    /// Stop playback and reset position
    pub fn stop(&mut self);

    /// Must be called each frame to refill buffers
    pub fn update(&mut self);

    /// Seek to position (0.0 - 1.0)
    pub fn seek(&mut self, position: f32);

    /// Get current position (0.0 - 1.0)
    pub fn position(&self) -> f32;

    /// Get duration in seconds
    pub fn duration(&self) -> f32;

    /// Check if playing
    pub fn is_playing(&self) -> bool;

    /// Set volume
    pub fn set_volume(&mut self, volume: f32);

    /// Set looping
    pub fn set_looping(&mut self, looping: bool);
}

/// Supported audio formats
#[derive(Clone, Copy)]
pub enum AudioFormat {
    Wav,
    Mp3,
    Ogg,
    Flac,
}

/// Audio errors
#[derive(Debug, thiserror::Error)]
pub enum AudioError {
    #[error("Failed to initialize audio: {0}")]
    InitError(String),

    #[error("Failed to load audio file: {0}")]
    LoadError(String),

    #[error("Unsupported format: {0}")]
    UnsupportedFormat(String),

    #[error("Audio system not initialized")]
    NotInitialized,
}
```

#### 2.3.4 Backend Implementations

**miniaudio backend (`backend_miniaudio.rs`):**

```rust
use miniaudio::{Device, DeviceConfig, DeviceType, Decoder};

pub(crate) struct AudioEngineInner {
    device: Device,
}

impl AudioEngineInner {
    pub fn new() -> Result<Self, AudioError> {
        let config = DeviceConfig::new(DeviceType::Playback);
        let device = Device::new(None, &config)
            .map_err(|e| AudioError::InitError(e.to_string()))?;
        device.start().map_err(|e| AudioError::InitError(e.to_string()))?;
        Ok(Self { device })
    }
}

pub(crate) struct SoundInner {
    decoder: Decoder,
    // ... playback state
}

// ... implement Sound/Music operations using miniaudio
```

**raylib backend (`backend_raylib.rs`):**

```rust
use raylib::prelude::*;

pub(crate) struct AudioEngineInner {
    _rl_audio: RaylibAudio,  // Keeps audio device alive
}

impl AudioEngineInner {
    pub fn new() -> Result<Self, AudioError> {
        let rl_audio = RaylibAudio::init_audio_device()
            .map_err(|e| AudioError::InitError(e.to_string()))?;
        Ok(Self { _rl_audio: rl_audio })
    }
}

pub(crate) struct SoundInner {
    sound: raylib::audio::Sound,
}

impl SoundInner {
    pub fn load(path: &str) -> Result<Self, AudioError> {
        let sound = raylib::audio::Sound::load_sound(path)
            .map_err(|e| AudioError::LoadError(e.to_string()))?;
        Ok(Self { sound })
    }

    pub fn play(&self) {
        self.sound.play();
    }

    // ... other methods
}

// ... implement Music using raylib::audio::Music
```

#### 2.3.5 Integration with Interpreter

Update `src/audio.rs` (or wherever audio builtins are implemented):

```rust
use crate::audio::{AudioEngine, Sound, Music, AudioError};

// Global audio engine (lazy initialized)
static AUDIO_ENGINE: OnceLock<Mutex<AudioEngine>> = OnceLock::new();

fn get_audio_engine() -> Result<&'static Mutex<AudioEngine>, AudioError> {
    AUDIO_ENGINE.get_or_try_init(|| {
        AudioEngine::new().map(Mutex::new)
    })
}

// Builtin: soond_play(path)
pub fn builtin_soond_play(args: &[Value]) -> Result<Value, RuntimeError> {
    let path = args[0].as_string()?;
    let _engine = get_audio_engine()?;  // Ensure initialized
    let sound = Sound::load(&path)?;
    sound.play();
    // Store sound handle somewhere to prevent drop...
    Ok(Value::Null)
}
```

### 2.4 Feature Configuration

Update `Cargo.toml`:

```toml
[features]
# Audio via miniaudio (standalone)
audio = ["miniaudio", "rustysynth"]

# Graphics includes raylib's built-in audio
graphics = ["raylib"]

# When graphics is enabled, don't include miniaudio
# (raylib provides audio functionality)

# Full features - now works on all platforms!
full = ["cli", "native", "graphics", "audio", "llvm"]
# On Windows, audio feature is effectively ignored when graphics is enabled
# because raylib provides the audio backend
```

**Conditional compilation in audio module:**

```rust
// In Cargo.toml dependencies:
[dependencies]
miniaudio = { version = "...", optional = true }
raylib = { version = "...", optional = true }
rustysynth = { version = "...", optional = true }  # Always optional, no conflict

// The audio module checks features:
#[cfg(all(feature = "audio", not(feature = "graphics")))]
compile_error!("When 'graphics' is enabled, audio is provided by raylib. \
                The 'audio' feature uses miniaudio which conflicts with raylib.");
```

Actually, we want them to work together. Better approach:

```rust
// audio/mod.rs
#[cfg(feature = "graphics")]
mod backend_raylib;

#[cfg(all(feature = "audio", not(feature = "graphics")))]
mod backend_miniaudio;

// Use raylib audio when graphics is enabled (regardless of audio feature)
#[cfg(feature = "graphics")]
pub use backend_raylib::*;

// Use miniaudio only when audio is enabled WITHOUT graphics
#[cfg(all(feature = "audio", not(feature = "graphics")))]
pub use backend_miniaudio::*;

// If neither, provide stub implementations or compile error
#[cfg(not(any(feature = "graphics", feature = "audio")))]
compile_error!("Either 'graphics' or 'audio' feature must be enabled for audio support");
```
