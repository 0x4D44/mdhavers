# Standard Library Reference

The standard library lives in `stdlib/` and is documented module by module in the [Standard Library](../stdlib/index.md) section: an index of all 59 modules grouped by area, how `fetch` finds them, and one page per module with every function and class.

Import a module with `fetch`:

```text
fetch "stdlib/bytes"
fetch "stdlib/strings" tae str
```

Quick links: [strings](../stdlib/strings.md), [maths](../stdlib/maths.md), [collections](../stdlib/collections.md), [functional](../stdlib/functional.md), [testing](../stdlib/testing.md), [datetime](../stdlib/datetime.md), [network_real](../stdlib/network_real.md), [concurrency](../stdlib/concurrency.md).
